   zero. `graphs/build.py` does this correctly; `find_top_activations.py` was never updated
   when RMS scale persistence was added (2026-04-30).

4. **Fix applied** to `scripts/find_top_activations.py`: load scales from checkpoint +
   normalize residuals before encoding. Needs rerun on pod.
